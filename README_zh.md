## 5 秒了解 PageDye

以往美化或定制网页，用户不得不面对繁琐的 CSS 语法、复杂选择器、DevTools 审查元素甚至编写 Tampermonkey 脚本。

**PageDye 改变了这一切。**

PageDye 是一款面向所有用户的 **AI 驱动、零代码网页视觉定制浏览器扩展**。无论是为刺眼的白色文档站换上护眼的深色磨砂玻璃、为常用网站加上极光粒子动态壁纸，还是用自然语言直接向 AI 描述想要的氛围，PageDye 都能在不破坏网页原有可读性的前提下瞬间完成视觉重塑。

- ❌ **不需要学 CSS / JavaScript**
- ❌ **不需要打开 DevTools 调试 DOM**
- ❌ **不需要为每个网站单独寻找特定主题插件**
- ✅ **自然语言描述 + 可视化滑块调色 + 全网通用适配**

## 三大核心支柱

### 🤖 1. AI 智能辅助 (AI-Assisted Customization)
- **上下文感知**：内置 AI 工作台能自动提取当前页面的配色特征与容器布局，生成与网页内容高度和谐的主题方案。
- **多轮对话微调**：无需推倒重来，支持多轮交互持续微调（如*“再暗一点”*、*“换成复古暖色调”*、*“增强科技感”*）。
- **硬性可读性保护**：内置可读性安全锁，严格保障原有网页正文文本的对比度与清晰度。
- **多模型与视觉支持**：自由接入 Claude、OpenAI、DeepSeek、OpenRouter 或本地 Ollama 模型，支持上传参考图片进行视觉引导。

### 🌐 2. 通用适配几乎所有网站 (Almost Any Website)
- **一套扩展，全网通用**：无需为 GitHub、YouTube、文档站等分别安装不同主题插件。
- **智能兼容引擎**：提供**标准、增强、强兼**三档模式，智能穿透网页自身不透明 CSS 遮罩。
- **可视化元素拾取**：支持点击网页上任意特定容器单独注入背景或应用磨砂玻璃。

### ⚡ 3. 完全零代码门槛 (Zero Code Required)
- **可视化操作体系**：颜色选取、渐变角度、毛玻璃模糊度、全局滤镜全由可视化滑块控制。
- **直觉式交互**：所见即所得，普通用户无需理解 Selector、Specificity 或 CSS 属性。

## 传统定制方式 vs PageDye

| 对比维度 | 传统方式 (Stylus / 脚本 / 手写 CSS) | PageDye (可视化 + AI 驱动) |
| :--- | :--- | :--- |
| **技能门槛** | 必须熟练掌握 CSS 语法与选择器 | **零门槛**：自然语言 Prompt 或拖动滑块 |
| **调试成本** | 需打开 DevTools 逐行排查 DOM | **所见即所得**：实时预览，一键生效 |
| **跨站维护** | 网站一旦重构或更新类名即失效 | **智能兼容引擎**：自动识别容器与层次 |
| **可读性保障** | 容易发生背景与文字颜色冲突 | **可读性安全锁**：自动校验文字对比度 |
| **动态与特效** | 手写复杂 Canvas/视频代码极度困难 | **开箱即用**：16 种 Shader、视频背景、光标一体化 |

## 安装与使用

### 桌面浏览器 (Chrome / Edge / Firefox / Brave)

1. **Microsoft Edge（推荐）**
   - 直接前往 [Microsoft Edge 附加组件商店](https://microsoftedge.microsoft.com/addons/detail/jdfkphphagodkilembkklhnepbnnkihh) 一键安装，享受自动静默更新。

2. **Chrome / Brave 等 Chromium 浏览器（离线加载）**
   - 从 [GitHub Releases](https://github.com/OnyxAxisOwO/PageDye/releases/latest) 下载最新版 `pagedye-v*.zip` 并解压。
   - 打开 `chrome://extensions`，开启右上角**开发者模式**。
   - 点击**加载已解压的扩展程序**，选择解压后的文件夹即可。

3. **Firefox (140+)**
   - 打开 `about:debugging#/runtime/this-firefox`。
   - 点击**临时载入附加组件…**，选择解压目录中的 `manifest.json`。

---

### 手机与平板 (PageDye Lite)

针对 Android、iPhone、iPad 与 Safari 用户，提供轻量单文件用户脚本 **PageDye Lite**：

1. 在 Android 上安装 **Tampermonkey**；在 iPhone/iPad 上安装 **Userscripts**（App Store 免费开源）。
2. 点击打开 [PageDye Lite 一键安装链接](https://raw.githubusercontent.com/OnyxAxisOwO/PageDye/main/userscript/pagedye.user.js)。
3. 在脚本管理器弹出的页面中确认安装即可。安装后任意网页右下角将出现控制面板悬浮按钮。

## 隐私与安全承诺

- **纯本地存储**：除主动配置并触发的 AI 请求外，PageDye 不向任何第三方服务器发送网页内容或配置数据。
- **严格敏感数据隔离**：AI 主题生成仅提取页面色彩与容器尺寸特征，**绝不读取网页文章正文、表单输入、密码或 Cookie**。
- **API 密钥安全**：用户的 API Key 仅保存在浏览器本地安全存储中，**导出备份文件时自动过滤剔除**。
- **零追踪**：无账号注册、无第三方广告 SDK、无用户行为遥测。

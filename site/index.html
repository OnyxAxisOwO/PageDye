通用适配几乎所有网站

无需为 GitHub、YouTube、文档站分别寻找不同插件。一个扩展，通用于几乎所有网页，并具备标准、增强与强兼兼容模式。

⚡

完全零代码门槛

不需要学 CSS，不需要懂 JavaScript，不需要打开 DevTools。所有调整都是可视化的滑块、调色盘、点选器与自然语言。

全方位的视觉定制能力

从背景、动效到毛玻璃与光标，所有工具开箱即用

AI 主题工作台 新

用自然语言描述想要的风格，AI 结合当前网页配色与布局智能生成主题，支持多轮对话持续微调色调、亮度与氛围。

多模型与视觉分析

可自由接入 Claude、OpenAI、DeepSeek、OpenRouter 或本地 Ollama 服务；支持附加图片进行视觉分析生成主题。

卡片磨砂玻璃

为网页内容容器添加高质感毛玻璃（Glassmorphism）效果，透出底层壁纸，模糊度与底色浓度均可独立无级调节。

丰富背景类型

支持纯色、线性/径向渐变、本地与网络高清图片（平铺/拉伸/适应），满足各种视觉需求。

16 种动态特效壁纸

内置 Matrix 雨、极光、星空粒子、落雪、打字机、波浪等 Canvas 动态着色器壁纸，支持自定义密度与播放速度。

本地视频背景

支持将本地 MP4 或 WebM 视频作为动态背景，支持透明度、模糊、铺满与播放控制，无需依赖远程视频服务器。

全局画面滤镜

精细调节亮度、对比度、灰度、反色、色相旋转、饱和度与透明度，轻松营造护眼或复古氛围。

个性化光标与动效

提供实心球、空心环、发光球与自定义图片光标，支持平滑跟随、鼠标拖尾及悬停放大交互。

可视化元素选择器

遇到复杂网站 CSS 遮挡时，直接点击网页上的任意目标元素注入背景，或切换增强/强兼模式清除遮罩。

昼夜联动与定时调度

跟随系统深浅色模式自动切换对应壁纸；支持按一天中的时间段自动更替，或按间隔时间幻灯片轮换。

细粒度网址规则

可按域名、子域名、路径前缀或完整 URL 分别设置不同视觉方案，规则支持优先级排序和临时禁用。

纯本地运行 · 隐私无忧

普通设置、图片和配置全部存储在浏览器本地，无账号体系、无广告、无遥测追踪；支持一键 JSON 备份与迁移。

告别手写代码，拥抱直觉定制

网页美化不该是程序员的专属特权

传统方式 (Stylus / 脚本 / 手写 CSS)

  • ✕ 必须学习 CSS 语法、选择器与布局规则
  • ✕ 需要打开 DevTools 一行行调试 DOM 元素
  • ✕ 网站一旦更新类名，写好的样式容易失效崩坏
  • ✕ 无法自动保证文字与背景的对比度可读性

PageDye (可视化 + AI 驱动)

  • ✓ 零代码：自然语言 Prompt 或拖动可视化滑块
  • ✓ AI 智能感知：自动分析网页配色并生成和谐主题
  • ✓ 智能兼容引擎：内置标准/增强/强兼模式清除遮挡
  • ✓ 可读性安全锁：严格保护原网页正文文字清晰可见

全平台支持

前往 GitHub Releases 下载最新版

Chrome / Brave 等 Chromium 内核浏览器

  1. 解压下载的压缩包
  2. 地址栏输入 chrome://extensions（Edge 为 edge://extensions）
  3. 打开右上角的开发者模式
  4. 点击加载已解压的扩展程序，选择解压后的文件夹

Firefox（需 140+；Firefox for Android 需 142+）

  1. 地址栏输入 about:debugging#/runtime/this-firefox
  2. 点击临时载入附加组件…
  3. 选择解压后文件夹内的 manifest.json

扩展未经 Mozilla 签名，只能以"临时扩展"方式加载，浏览器重启后需要重新加载一次。

手机 / 平板：PageDye Lite

精简的用户脚本（UserScript）版本，核心渲染逻辑和扩展版共享，通过脚本管理器运行。

已经装好 Tampermonkey / Violentmonkey / Userscripts 的话，直接点这个：

一键安装 PageDye Lite

点击后脚本管理器会自动弹出安装确认页面，确认即可，不需要手动复制粘贴代码。

Android — Edge / Firefox

  1. 在浏览器的扩展 / 附加组件商店搜索并安装 Tampermonkey
  2. 回到本页，点上面的一键安装按钮

Chrome 移动版官方不支持任何扩展，装不了 Tampermonkey；可以换用 Edge、Firefox，或 Kiwi Browser 等支持扩展的第三方 Chromium 分支。

iOS / iPadOS — Safari

  1. App Store 搜索安装 Userscripts（作者 Quoid，免费开源）
  2. 设置 → Safari → 扩展 → 启用 Userscripts，并允许在所有网站上运行
  3. 回到本页，点上面的一键安装按钮

安装完成后，打开任意网站，右下角会出现一个悬浮按钮，点开即为设置面板；按钮外观与行为均可在高级设置中自定义。
